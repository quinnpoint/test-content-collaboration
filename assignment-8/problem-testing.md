# Problem Testing

To ensure our a solution has been found and our goal met for the project, we will follow the below tests.

1. Functional: Properly assign students to different parking garages as needed; if students are being assigned to different spaces dynamically, the test is passed. If students are not being assigned to different garages however, this is indicative of an issue with the program, so the test is failed.
2. Nonfunctional: Create runnable commands to pull data from the database; if valid entries are returned, then the test is passed. Otherwise, the test is failed.
3. Nonfunctional: Accurately identify and store license plate data into the database using security cameras or staff recordings. If the data enters the database properly, the test is passed. Otherwise, the test is failed.
